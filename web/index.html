ล็อกอิน Google

OAuth 2.0 เต็มรูปแบบ เซสชันเก็บในคุกกี้แบบ httponly โทเคนทั้งหมดเข้ารหัสก่อนบันทึกลงฐานข้อมูล และจำกัดผู้ใช้ตามอีเมลหรือโดเมนได้

⚡

ยืมการ์ดจอ

จับคู่ Colab ด้วยรหัสใช้ครั้งเดียว เห็น VRAM / การใช้งาน GPU แบบสด ๆ เพิ่มได้หลายเครื่อง ระบบจะกระจายงานให้เอง

🗄️

rclone อัตโนมัติ

สร้าง rclone.conf จากสิทธิ์ที่คุณอนุญาตไว้แล้ว เครื่อง Colab ดึงไปเมานต์ Drive ได้เอง อ่านไฟล์ 5TB เหมือนโฟลเดอร์ในเครื่อง

🧠

คลังความรู้ Vault

ค้นเอกสารด้วยความหมาย ไม่ใช่แค่คำตรง รองรับภาษาไทยที่ไม่เว้นวรรค และใช้งานได้ทันทีแม้ยังไม่มี GPU ว่าง

📡

เห็นทุกอย่างแบบสด
