# FGP Production System

ระบบบริหารการผลิตของแผนก FGP รวมยอดผลิต แผนการผลิต กำลังคน การจองคิวคน
และการวิเคราะห์อัจฉริยะไว้ในเว็บแอปเดียว

เขียนด้วย Python ล้วน **ไม่ต้องติดตั้ง library ใดๆ เพิ่ม** ไม่ต้องต่ออินเทอร์เน็ต
เปิดเครื่องเดียวแล้วให้ทุกคนในวง LAN เข้าใช้ผ่านเบราว์เซอร์ได้ทันที

---

## เริ่มใช้งาน

### Windows

ดับเบิลคลิก **`start.bat`**

เบราว์เซอร์จะเปิดขึ้นมาเอง และหน้าจอ command จะบอก IP สำหรับให้เครื่องอื่นเข้าใช้

### Linux / macOS

```bash
./start.sh
```

### เครื่องที่มี Python อยู่แล้ว (ทุกระบบ)

```bash
python3 -m fgp
```

### ทำให้พกพาได้จริง (เครื่องที่ไม่มี Python)

1. โหลด [Python Embeddable Package](https://www.python.org/downloads/windows/) (ไฟล์ zip)
2. แตกไฟล์แล้วเปลี่ยนชื่อโฟลเดอร์เป็น `python` วางไว้ข้าง `start.bat`
3. ก๊อบทั้งโฟลเดอร์ลง USB แล้วเสียบเครื่องไหนก็ใช้ได้ทันที

`start.bat` จะหาโฟลเดอร์ `python` ก่อนเสมอ ถ้าไม่เจอจึงค่อยใช้ Python ที่ติดตั้งในเครื่อง

---

## ให้เครื่องอื่นเข้าใช้ผ่าน LAN

ตอนเปิดระบบ หน้าจอจะแสดงที่อยู่ไว้ให้ เช่น

```
เครื่องนี้          http://localhost:8080
เครื่องอื่นในวง LAN  http://192.168.1.45:8080
จอ Andon           http://192.168.1.45:8080/#/andon
```

เอาที่อยู่บรรทัดกลางไปเปิดในเบราว์เซอร์ของเครื่องอื่น หรือมือถือที่ต่อ Wi-Fi วงเดียวกัน

ถ้าเข้าไม่ได้ ให้อนุญาต Python ผ่าน Windows Firewall ในหน้าต่างที่เด้งขึ้นครั้งแรก
(เลือก Private network) หรือเปิดพอร์ต 8080 เอง

## บัญชีเริ่มต้น

| ชื่อผู้ใช้ | รหัสผ่าน | สิทธิ์ | ทำอะไรได้ |
|---|---|---|---|
| `admin` | `Admin@123` | ผู้ดูแลระบบ | ทุกอย่าง รวมถึงจัดการผู้ใช้ |
| `manager` | `Manager@123` | หัวหน้าแผนก | ตั้งค่าไลน์ รุ่นสินค้า ดูประวัติทั้งหมด |
| `leader1` | `Leader@123` | หัวหน้าไลน์ | วางแผน จองคน มอบหมายงาน |
| `operator` | `Operator@123` | พนักงาน | บันทึกยอดผลิต ปิดงานที่ได้รับ |

**เปลี่ยนรหัสผ่านทุกบัญชีก่อนใช้งานจริง** ที่เมนู ตั้งค่าระบบ

## ความสามารถ

### การผลิต
- **แดชบอร์ด** ยอดผลิต เทียบเป้า Yield เวลาหยุดเครื่อง OEE และแนวโน้ม 14 วัน
- **บันทึกยอดผลิต** กรอกรายชั่วโมงต่อไลน์ พร้อมของเสีย เวลาหยุด และสาเหตุ
- **แผนการผลิต** วางแผนล่วงหน้า ดูเป็นตาราง 7 วัน คัดลอกแผนข้ามวันได้ในคลิกเดียว
- **จอ Andon** หน้าจอใหญ่สำหรับติดหน้าไลน์ ตัวเลขใหญ่ อัปเดตเองทุก 20 วินาที

### กำลังคน
- **จองคิวคน** เปิดคิวขอคนล่วงหน้า ระบุจำนวนและระดับทักษะขั้นต่ำที่ต้องการ
- **พนักงาน & ทักษะ** ทะเบียนกำลังคนและตารางทักษะรายไลน์ (Skill Matrix ระดับ 0-4)
- **กระจายงาน Leader** บอร์ดงานสามช่อง รอเริ่ม / กำลังทำ / เสร็จแล้ว

### ระบบอัจฉริยะ
ทุกฟังก์ชันคำนวณจากข้อมูลจริงในฐานข้อมูล และอธิบายที่มาของคำตอบได้เสมอ

| ฟังก์ชัน | ทำอะไร | วิธีคิด |
|---|---|---|
| พยากรณ์จบกะ | บอกว่าไลน์นี้จะจบกะที่กี่ชิ้น | ค่าเฉลี่ยถ่วงน้ำหนัก ชั่วโมงล่าสุดสำคัญกว่า บวกแนวโน้มครึ่งหลังของกะ |
| จัดคนอัตโนมัติ | เลือกคนที่เหมาะที่สุดเข้าคิวจอง | ให้คะแนนจากทักษะตรงไลน์ ตรงกะ ความว่าง และความเป็นธรรมของภาระงาน |
| ตรวจความผิดปกติ | จับ NG พุ่ง ยอดตก เครื่องหยุดนาน | z-score เทียบพฤติกรรมปกติของไลน์นั้นเอง ไม่ใช้เกณฑ์ตายตัว |
| หาคอขวด | บอกว่าไลน์ไหนรับงานเกินกำลัง | เทียบเวลาที่ต้องใช้ผลิต กับเวลาของกะหลังหักเวลาหยุดเครื่อง |
| เสนอย้ายงาน | บอกว่าควรย้ายกี่ชิ้นจากไลน์ไหนไปไหน | จับคู่ไลน์ที่ล้นกับไลน์ที่ยังมีเวลาว่าง |
| คำนวณ OEE | Availability x Performance x Quality | สูตร Nakajima มาตรฐาน พร้อมชี้ว่าตัวไหนฉุด |
| พาเรโตเวลาหยุด | เรียงสาเหตุที่กินเวลามากที่สุด | รวมเวลาตามสาเหตุ พร้อมเส้นสะสม |
| ที่ปรึกษาประจำกะ | รวมทุกสัญญาณเป็นสิ่งที่ควรทำตอนนี้ | เรียงตามความเร่งด่วน ทุกข้อมีเหตุผลและวิธีแก้กำกับ |
| ประเมินกำลังคน | บอกว่ากะนี้คนพอหรือไม่ | เทียบคนที่มีในกะกับมาตรฐานของไลน์ที่ต้องเดิน |
| แจ้งเตือนอัตโนมัติ | บันทึกความเสี่ยงระดับสูงไว้ให้กดรับทราบ | สร้างจากที่ปรึกษาประจำกะ กันซ้ำภายในวันเดียวกัน |

## ข้อมูลและการสำรอง

ข้อมูลทั้งหมดอยู่ในไฟล์เดียว: **`data/fgp.db`** (SQLite)

- **สำรองข้อมูล** คัดลอกโฟลเดอร์ `data` ทั้งโฟลเดอร์เก็บไว้
- **ย้ายเครื่อง** ก๊อบโฟลเดอร์ `data` ไปวางที่เครื่องใหม่
- **ล้างเริ่มใหม่** `python3 -m fgp --reset` (ลบข้อมูลเดิมแล้วสร้างข้อมูลตัวอย่างใหม่)
- **เริ่มจากศูนย์** `python3 -m fgp --empty` (ฐานข้อมูลเปล่า ไม่มีข้อมูลตัวอย่าง)

ครั้งแรกที่เปิด ระบบจะสร้างข้อมูลตัวอย่าง 5 ไลน์ 5 รุ่นสินค้า พนักงาน 64 คน
และยอดผลิตย้อนหลัง 30 วัน เพื่อให้ลองใช้ได้ทันที

## ตัวเลือกตอนเปิดระบบ

```bash
python3 -m fgp --port 9000      # เปลี่ยนพอร์ต (ค่าเริ่มต้น 8080)
python3 -m fgp --no-browser     # ไม่ต้องเปิดเบราว์เซอร์ให้
python3 -m fgp --host 127.0.0.1 # ให้เข้าได้เฉพาะเครื่องนี้
python3 -m fgp --reset          # ล้างข้อมูลแล้วสร้างตัวอย่างใหม่
python3 -m fgp --empty          # ฐานข้อมูลเปล่า
```

ถ้าพอร์ตที่ขอถูกใช้อยู่ ระบบจะเลื่อนไปพอร์ตถัดไปให้เองอัตโนมัติ

## ความปลอดภัย

- รหัสผ่านเก็บด้วย PBKDF2-SHA256 120,000 รอบ พร้อม salt เฉพาะราย ไม่เก็บรหัสจริง
- Session เป็น cookie แบบ HttpOnly อายุ 7 วัน
- ใส่รหัสผิดเกิน 10 ครั้งใน 5 นาที จะถูกพักไว้ชั่วคราว (นับเฉพาะครั้งที่ผิด
  เครื่องรวมหน้าไลน์จึงใช้ร่วมกันได้)
- แบ่งสิทธิ์ 5 ระดับ ตรวจที่ฝั่งเซิร์ฟเวอร์ทุกครั้ง ไม่ได้เชื่อฝั่งหน้าเว็บ
- บันทึกประวัติการใช้งานสำคัญไว้ในตาราง audit

ระบบนี้ออกแบบสำหรับเครือข่ายภายในโรงงาน ถ้าจะเปิดออกอินเทอร์เน็ต
ต้องวางหลัง reverse proxy ที่มี HTTPS เสมอ
