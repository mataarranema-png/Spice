# FGP Production Suite

ระบบจัดการการผลิตสำหรับฝ่าย FGP รันในเครื่องตัวเอง เปิดด้วยการดับเบิลคลิกครั้งเดียว
ไม่ต้องติดตั้งไลบรารีเพิ่ม ไม่ต้องต่ออินเทอร์เน็ต และข้อมูลไม่ออกไปไหน

---

## เปิดโปรแกรมยังไง

| เครื่องที่ใช้ | ทำอะไร |
|---|---|
| Windows | ดับเบิลคลิก **START-WINDOWS.bat** |
| macOS | ดับเบิลคลิก **start-mac.command** |
| Linux | รัน `./start-linux.sh` |
| ทุกเครื่อง | หรือพิมพ์ `python start.py` ในโฟลเดอร์นี้ |

เบราว์เซอร์จะเปิดขึ้นมาเองที่ `http://localhost:8760`
ถ้าพอร์ตนั้นไม่ว่าง ระบบจะขยับไปพอร์ตถัดไปให้เองและบอกที่อยู่ที่หน้าต่างสีดำ

**ปิดโปรแกรม** กด `Ctrl + C` ที่หน้าต่างสีดำ หรือปิดหน้าต่างนั้นทิ้ง

### ถ้าเครื่องยังไม่มี Python

โหลดฟรีที่ <https://www.python.org/downloads/> ต้องเป็นรุ่น 3.8 ขึ้นไป
ตอนติดตั้งบน Windows **ให้ติ๊กช่อง "Add Python to PATH"** ด้วย ไม่งั้นไฟล์ .bat จะหา Python ไม่เจอ

## ในระบบมีอะไรบ้าง

ทั้งเจ็ดหน้าทำงานกับข้อมูลชุดเดียวกัน แก้ที่หน้าหนึ่งแล้วอีกหน้าจะเปลี่ยนตามทันที

**1. ภาพรวมทั้งฝ่าย**
ตัวเลขสำคัญของวันนี้ เรื่องที่ต้องตัดสินใจ กราฟแผนเทียบผลจริง งานค้างตามขั้นตอน และงานที่ต้องดูก่อนใคร

**2. แผนผลิต Plan vs Actual**
แผนรายวันและรายสัปดาห์ เปอร์เซ็นต์ที่ทำได้ ส่วนต่างจากแผน แยกตามรุ่น ไลน์ และกะ
บันทึกผลผลิตจริงและเพิ่มแผนใหม่ได้จากหน้านี้เลย

**3. จองคิวเครื่องและ Chamber**
ผังเวลาของเครื่องทุกตัวใน 1 วัน เห็นทันทีว่าเครื่องไหนว่างช่วงไหน
จองคิวได้เลย ระบบกันคิวชนให้ และบอกว่าชนกับใครเวลาไหน เครื่องที่ปิดซ่อมจะจองไม่ได้

**4. ติดตามงาน WIP**
งานทุกใบเดินผ่านหกขั้นตอน ตั้งแต่รับงานจนปิดงาน
ตอบได้ว่างานอยู่ขั้นไหน อยู่กับใคร ค้างมากี่วัน และคาดว่าจะเสร็จเมื่อไร
เปิดใบงานเพื่อดูประวัติ ส่งต่อขั้นถัดไป หรือโยกให้คนอื่นได้

**5. KPI การผลิต**
Output, Productivity, ชั่วโมง OT, Utilization, Yield และ OEE พร้อมกราฟย้อนหลังและตารางไว้ทำรายงาน

**6. Leader Control Tower**
เห็นว่าลูกทีมใครว่าง ใครงานล้น ระบบจับคู่คนที่ล้นกับคนที่ว่างและถนัดงานแบบเดียวกัน
หัวหน้าเป็นคนกดอนุมัติการโยกเอง และมอบหมายงานเองก็ได้

**7. การแจ้งเตือนเชิงธุรกิจ**
ระบบอ่านข้อมูลจริงแล้วเตือนเรื่อง Chamber เต็ม, capacity เหลือน้อย, งานจะเลยกำหนดส่ง,
งานค้างขั้นเดิมนานเกินไป, กำลังคนไม่พอ, ผลผลิตต่ำกว่าแผน, Yield ตก และ OEE ต่ำ
กดรับทราบเพื่อซ่อนไว้จนสิ้นวันได้

## เรื่องข้อมูล

ครั้งแรกที่เปิด ระบบจะสร้างไฟล์ `data/fgp.db` พร้อมข้อมูลตัวอย่างที่อิงกับวันที่ของวันนั้น
ทุกอย่างที่แก้ในหน้าจอจะถูกบันทึกลงไฟล์นี้ และยังอยู่ครบเมื่อเปิดใหม่

- **สำรองข้อมูล** ก๊อบปี้ไฟล์ `data/fgp.db` เก็บไว้
- **เริ่มใหม่ทั้งหมด** ลบไฟล์ `data/fgp.db` แล้วเปิดโปรแกรมใหม่ หรือรัน `python start.py --reset`
- **ย้ายเครื่อง** ก๊อบปี้ทั้งโฟลเดอร์นี้ไปวางที่เครื่องใหม่ ข้อมูลไปด้วย

ถ้าจะใช้กับข้อมูลจริงของฝ่าย ให้ลบข้อมูลตัวอย่างออกก่อนด้วย `--reset` แล้วค่อยกรอกของจริง
หรือแก้รายชื่อรุ่น พนักงาน และเครื่องมือได้ที่ `app/database.py` ส่วนบนสุดของไฟล์

## ตัวเลือกตอนเปิดโปรแกรม

```
python start.py                  เปิดปกติ
python start.py --port 9000      กำหนดพอร์ตเอง
python start.py --no-browser     ไม่ต้องเปิดเบราว์เซอร์ให้
python start.py --reset          ล้างข้อมูลแล้วสร้างข้อมูลตัวอย่างใหม่
python start.py --host 0.0.0.0   ให้เครื่องอื่นในวงแลนเปิดดูได้ด้วย
```

> `--host 0.0.0.0` เปิดให้ทุกเครื่องในวงเน็ตเวิร์กเดียวกันเข้าถึงได้ และระบบนี้ไม่มีระบบล็อกอิน
> ใช้เฉพาะในเครือข่ายภายในที่ไว้ใจได้เท่านั้น

## ปุ่มที่ใช้บ่อย

- ปุ่ม **◐** มุมขวาบน สลับระหว่างโหมดมืดกับโหมดสว่าง เครื่องจะจำไว้ให้
- ปุ่ม **↻ รีเฟรช** ดึงข้อมูลล่าสุดมาแสดงใหม่
- กด **Esc** ปิดหน้าต่างที่เด้งขึ้นมา
- บนมือถือ กดปุ่ม **☰** เพื่อเปิดเมนู

## โครงสร้างไฟล์

```
FGP-Production-Suite/
├── START-WINDOWS.bat     เปิดโปรแกรมบน Windows
├── start-mac.command     เปิดโปรแกรมบน macOS
├── start-linux.sh        เปิดโปรแกรมบน Linux
├── start.py              ตัวเปิดโปรแกรมหลัก
├── app/
│   ├── database.py       โครงฐานข้อมูลและข้อมูลตัวอย่าง
│   ├── api.py            การคำนวณทั้งหมด แผน คิวเครื่อง WIP KPI และการแจ้งเตือน
│   └── server.py         เว็บเซิร์ฟเวอร์
├── web/
│   ├── index.html        โครงหน้าจอ
│   ├── css/app.css       ระบบดีไซน์ทั้งหมด
│   └── js/               core, charts, views, app
└── data/fgp.db           ฐานข้อมูล สร้างเองตอนเปิดครั้งแรก
```

ทั้งหมดเขียนด้วยไลบรารีมาตรฐานของ Python กับ HTML, CSS, JavaScript ล้วน
ไม่มี framework ไม่มี build step และไม่โหลดอะไรจากอินเทอร์เน็ตเลย
